Что это

Тот же qWDTT, но на Windows

Android-версия поднимает системный VPN и уводит трафик через TURN-серверы VK: для сети это похоже на медиатрафик звонка. pyWDTT переносит схему на компьютер и вместо системного VPN отдаёт локальный прокси.

Один файл

Копируется на флешку и запускается двойным кликом.

Офлайн

18 колёс для Python 3.7–3.13 внутри, pip не нужен.

Прокси

HTTP и SOCKS5 на 127.0.0.1:1080, авторизация по желанию.

Криптография

Нативная через cryptography, иначе встроенная на чистом Python.

Установка

Скачали — запустили

Нужен только Python и системный компонент Edge WebView2 — он есть в Windows 10 и 11.

1. Скачайте pyWDTT.pyw
2. Положите в любую папку, например C:\Apps
3. Двойной клик — откроется окно pyWDTT
cd C:\Apps
python pyWDTT.pyw     :: с консолью и логом
pythonw pyWDTT.pyw    :: без консольного окна
certutil -hashfile pyWDTT.pyw SHA256
:: или: Get-FileHash pyWDTT.pyw -Algorithm SHA256

Что нужно

Windows 10 или 11, x64 либо x86, Python 3.7–3.13, WebView2 Runtime. Остальное файл делает сам.

Вопросы

Коротко о главном

Окно не открылось — где смотреть причину?

В %TEMP%\qwdtt-window.log: Win+R → %TEMP% → файл qwdtt-window.log. Запуск через python pyWDTT.pyw покажет ошибку и в консоли.

Нужен ли интернет, кроме туннеля?

Нет. Все библиотеки внутри файла, интерфейс локальный. Сеть нужна только самому туннелю.

Антивирус ругается

Неизвестный файл, который шифрует трафик и пишет в %TEMP%, выглядит подозрительно для эвристики. Сверьте SHA-256 выше и добавьте в исключения, если доверяете источнику.
